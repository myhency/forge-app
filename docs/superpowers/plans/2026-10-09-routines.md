# Routines Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A person can save a prompt with a folder and a schedule as a routine; while Forge is open it starts a normal session from the routine when the time comes, and they can run, pause, edit, delete a routine and see its history.

**Architecture:** A pure schedule engine and decision function in `forge-domain` (all five schedule tabs are turned into one cron expression, run by the `cron` crate over `chrono` time zones). A `RoutinesUseCase` keeps routines and run history in Forge's config under the shared `ConfigLock`. A `RoutineRunner` in `forge-application` decides on each 30 second tick and asks a `RoutineHost` (a trait; `RegistryHost` opens a session in the `SessionRegistry`) to start the session. The UI thread owns the tick loop, adopts the started sessions into the workspace and draws three screens (list, detail, form).

**Tech Stack:** Rust workspace (hexagonal crates), Dioxus 0.7 desktop, `cron` + `chrono` (new), `tokio`, mockall, the Node sidecar (TypeScript, vitest).

**Spec:** `docs/superpowers/specs/2026-10-09-routines-design.md` (read it first; this plan lists where it differs, under "Deviations from the spec").

## Global Constraints

- Local routines only; no cloud item, no Templates tab, no desktop-app interop. Everything is stored in Forge's config; `~/.claude/scheduled-tasks/` and the desktop app's `scheduled-tasks.json` are never read or written.
- A routine that needs a permission waits in its session; nothing is approved or denied by itself.
- A run more than 30 minutes past its due time is not run: one `Skipped(Missed)` is recorded (`MISSED_AFTER_MS = 1_800_000`).
- Random delay is a fixed 0 to 5 minutes taken from a hash of the routine id (`MAX_DELAY_MS = 300_000`), none for `Manual` or "Run now", none when two occurrences are less than 10 minutes apart.
- History keeps the latest 50 runs per routine (`KEEP_RUNS = 50`).
- The runner ticks every 30 seconds. Every config write goes through the one `ConfigLock`; an unreadable config is never replaced.
- Config fields are `#[serde(default)]`, so an old config loads.
- UI text is English, like the rest of Forge ("Routines", "New routine", "Run now", "Paused").
- Never put a routine's name, folder or text into a shell line (the notification adapter passes them as separate arguments).
- Commits end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Deviations from the spec

1. **One engine.** The spec described `next_after(schedule, after_ms, offset_at)` with a caller-supplied UTC offset. Every schedule tab maps to a cron expression, so one `cron`-crate engine over `chrono::TimeZone` does all of them, and daylight saving is handled by the time zone (`chrono::Local` in the app, `FixedOffset` in tests). Same behaviour, simpler code.
2. **No "Worktree" checkbox.** Forge sessions have no worktree support anywhere in the code (checked), so the checkbox would do nothing. It is left out until sessions can use worktrees; no `worktree` field is stored.
3. **Folder is required** (the spec only required name and description). A routine with no folder cannot run, so "Create" stays off until name, description and a folder are set.
4. **Plain selects.** The form's permission mode and model are `<select>` elements fed by `mode_options()` and `model_options()` (as the Settings screen does), and the folder is chosen with the folder picker button, not the composer's pickers and folder menu.
5. **Finished routine sessions are closed by Forge.** A routine every hour would otherwise leave a sidecar process per run until the app quits. When a routine's turn is finished and the session is not the one on screen, Forge closes it (the transcript stays on disk and the session stays in the sidebar as a past session). This is not in the spec; it is needed so the feature is usable.

## Review Focus

Failure modes the spec implies but no feature task would test by itself. Each has a test in the task named.

1. The computer's clock moves back (`baseline` is in the future): the routine must wait, not run or crash. (Task 1, `decide`)
2. The config cannot be read when the runner ticks: the tick reports the error, writes nothing and does not replace the file. (Task 3)
3. Two routines in the same folder are due at the same tick: the second sees the first as busy and records `Skipped(Busy)`; the first is not run twice. (Task 3)
4. A cron expression that is garbage or has a zero step (`*/0`, `61 * * * *`, four fields): the form refuses it, and a routine that already holds one is treated as "never due", not a crash. (Task 1, Task 3)
5. The app was closed for days under a once-a-minute schedule: one `Skipped(Missed)` is recorded, not one per minute, and the history stays at 50. (Task 1, Task 2)

```rust
use std::path::PathBuf;
use std::str::FromStr;

use chrono::{DateTime, TimeZone};
use serde::{Deserialize, Serialize};

use crate::PermissionMode;

/// A run more than this far past its due time is not run (Forge was closed or the computer asleep).
pub const MISSED_AFTER_MS: i64 = 30 * 60 * 1000;
/// The random delay the real app mentions, fixed per routine: 0 up to this.
pub const MAX_DELAY_MS: i64 = 5 * 60 * 1000;
/// Schedules with two occurrences closer than this get no delay (it would reorder them).
const MIN_GAP_FOR_DELAY_MS: i64 = 10 * 60 * 1000;
/// History kept per routine.
pub const KEEP_RUNS: usize = 50;
/// How many occurrences `decide` walks before it stops looking for the latest one.
const SCAN_LIMIT: usize = 2000;

const DAY_NAMES: [&str; 7] = ["SUN", "MON", "TUE", "WED", "THU", "FRI", "SAT"];
const DAY_WORDS: [&str; 7] = ["Sunday", "Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday"];
const FIVE_FIELDS: &str = "A cron expression has five fields: minute hour day month weekday";

/// When a routine runs. These are the six tabs of the form. `day` is 0 (Sunday) to 6.
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(tag = "kind", rename_all = "snake_case")]
pub enum Schedule {
    Manual,
    Hourly,
    Daily { hour: u8, minute: u8 },
    Weekdays { hour: u8, minute: u8 },
    Weekly { day: u8, hour: u8, minute: u8 },
    Cron { expression: String },
}

impl Schedule {
    /// The expression the `cron` crate runs: seconds first, weekdays by name (the crate counts them
    /// from another starting number than the usual `0` or `7` for Sunday).
    fn engine_text(&self) -> Result<Option<String>, String> {
        let text = match self {
            Schedule::Manual => return Ok(None),
            Schedule::Hourly => "0 0 * * * *".to_string(),
            Schedule::Daily { hour, minute } => format!("0 {minute} {hour} * * *"),
            Schedule::Weekdays { hour, minute } => format!("0 {minute} {hour} * * MON-FRI"),
            Schedule::Weekly { day, hour, minute } => {
                let name = DAY_NAMES.get(usize::from(*day)).ok_or("The day must be 0 to 6")?;
                format!("0 {minute} {hour} * * {name}")
            }
            Schedule::Cron { expression } => engine_expression(expression)?,
        };
        Ok(Some(text))
    }

    fn engine(&self) -> Result<Option<cron::Schedule>, String> {
        match self.engine_text()? {
            None => Ok(None),
            Some(text) => cron::Schedule::from_str(&text).map(Some).map_err(|error| error.to_string()),
        }
    }

    /// Why this schedule cannot be used, in words for the form.
    pub fn validate(&self) -> Result<(), String> {
        match self {
            Schedule::Daily { hour, minute } | Schedule::Weekdays { hour, minute } | Schedule::Weekly { hour, minute, .. }
                if *hour > 23 || *minute > 59 =>
            {
                return Err("The time must be 00:00 to 23:59".to_string());
            }
            _ => {}
        }
        self.engine().map(|_| ())
    }

    /// The first time strictly after `after`; `None` for `Manual` and for a schedule that cannot be read.
    pub fn next_after<Tz: TimeZone>(&self, after: &DateTime<Tz>) -> Option<DateTime<Tz>> {
        let engine = self.engine().ok()??;
        engine.after(after).next()
    }

    /// How a card and the detail screen say it: "Every day at 9:00 AM".
    pub fn label(&self) -> String {
        match self {
            Schedule::Manual => "Manual".to_string(),
            Schedule::Hourly => "Every hour".to_string(),
            Schedule::Daily { hour, minute } => format!("Every day at {}", clock(*hour, *minute)),
            Schedule::Weekdays { hour, minute } => format!("Weekdays at {}", clock(*hour, *minute)),
            Schedule::Weekly { day, hour, minute } => {
                format!("Every {} at {}", DAY_WORDS.get(usize::from(*day)).copied().unwrap_or("day"), clock(*hour, *minute))
            }
            Schedule::Cron { expression } => format!("Cron {expression}"),
        }
    }
}

fn clock(hour: u8, minute: u8) -> String {
    let (twelve, suffix) = match hour {
        0 => (12, "AM"),
        1..=11 => (hour, "AM"),
        12 => (12, "PM"),
        _ => (hour - 12, "PM"),
    };
    format!("{twelve}:{minute:02} {suffix}")
}

/// Five usual fields in, the six the engine wants out. A bad count is refused here, in words.
fn engine_expression(expression: &str) -> Result<String, String> {
    let fields: Vec<&str> = expression.split_whitespace().collect();
    if fields.len() != 5 {
        return Err(FIVE_FIELDS.to_string());
    }
    Ok(format!("0 {} {} {} {} {}", fields[0], fields[1], fields[2], fields[3], weekday_names(fields[4])))
}

/// `1-5`, `0,6` and `*/2` in the usual numbers become names; `*` and names stay.
fn weekday_names(field: &str) -> String {
    field
        .split(',')
        .map(|part| {
            let (range, step) = match part.split_once('/') {
                Some((range, step)) => (range, Some(step)),
                None => (part, None),
            };
            let range = range.split('-').map(day_name).collect::<Vec<_>>().join("-");
            match step {
                Some(step) => format!("{range}/{step}"),
                None => range,
            }
        })
        .collect::<Vec<_>>()
        .join(",")
}

fn day_name(token: &str) -> String {
    match token {
        "0" | "7" => "SUN",
        "1" => "MON",
        "2" => "TUE",
        "3" => "WED",
        "4" => "THU",
        "5" => "FRI",
        "6" => "SAT",
        other => other,
    }
    .to_string()
}

}

/// What a tick should do about one routine.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Decision {
    Wait,
    Run { due_ms: i64 },
    Missed { due_ms: i64 },
}

/// A fixed offset of 0 to `MAX_DELAY_MS`, from a hash of the id (FNV-1a), so the same routine is
/// always late by the same amount.
pub fn delay_ms(id: &str) -> i64 {
    let mut hash: u64 = 0xcbf29ce484222325;
    for byte in id.bytes() {
        hash ^= u64::from(byte);
        hash = hash.wrapping_mul(0x100000001b3);
    }
    (hash % MAX_DELAY_MS as u64) as i64
}

fn delay_for<Tz: TimeZone>(schedule: &Schedule, id: &str, first: &DateTime<Tz>) -> i64 {
    match schedule.next_after(first) {
        Some(second) if second.timestamp_millis() - first.timestamp_millis() >= MIN_GAP_FOR_DELAY_MS => delay_ms(id),
        Some(_) => 0,
        None => delay_ms(id),
    }
}

/// What to do about `routine` at `now_ms`. Of all the times that passed since the baseline only the
/// latest counts: it runs when it is at most `MISSED_AFTER_MS` late and is recorded as one skip when
/// it is later.
pub fn decide<Tz: TimeZone>(routine: &Routine, now_ms: i64, zone: &Tz) -> Decision {
    if !routine.enabled || matches!(routine.schedule, Schedule::Manual) {
        return Decision::Wait;
    }
    let Some(start) = zone.timestamp_millis_opt(routine.baseline).single() else {
        return Decision::Wait;
    };
    let Some(first) = routine.schedule.next_after(&start) else {
        return Decision::Wait;
    };
    let delay = delay_for(&routine.schedule, &routine.id, &first);
    let mut latest = None;
    let mut current = first;
    for _ in 0..SCAN_LIMIT {
        let due = current.timestamp_millis() + delay;
        if due > now_ms {
            break;
        }
        latest = Some(due);
        match routine.schedule.next_after(&current) {
            Some(next) => current = next,
            None => break,
        }
    }
    match latest {
        None => Decision::Wait,
        Some(due_ms) if now_ms - due_ms <= MISSED_AFTER_MS => Decision::Run { due_ms },
        Some(due_ms) => Decision::Missed { due_ms },
    }
}

/// A slug of `name` that no id in `taken` has: `a`, then `a-2`, `a-3`. Letters of any language stay.
pub fn routine_id(name: &str, taken: &[String]) -> String {
    let mut slug = String::new();
    let mut dash = false;
    for character in name.trim().chars() {
        if character.is_alphanumeric() {
            if dash && !slug.is_empty() {
                slug.push('-');
            }
            dash = false;
            slug.extend(character.to_lowercase());
        } else {
            dash = true;
        }
    }
    if slug.is_empty() {
        slug = "routine".to_string();
    }
    let mut candidate = slug.clone();
    let mut number = 2;
    while taken.iter().any(|id| *id == candidate) {
        candidate = format!("{slug}-{number}");
        number += 1;
    }
    candidate
}

/// Why a draft cannot be saved, in words for the form (the first problem only).
pub fn validate_draft(draft: &RoutineDraft) -> Result<(), String> {
    if draft.name.trim().is_empty() {
        return Err("Name is required".to_string());
    }
    if draft.description.trim().is_empty() {
        return Err("Description is required".to_string());
    }
    if draft.folder.is_none() {
        return Err("Choose a folder".to_string());
    }
    draft.schedule.validate()
}

/// Adds a run and drops the oldest of the same routine beyond `KEEP_RUNS`.
pub fn push_run(runs: &mut Vec<RoutineRun>, run: RoutineRun) {
    let routine = run.routine_id.clone();
    runs.push(run);
    let mut extra = runs.iter().filter(|run| run.routine_id == routine).count().saturating_sub(KEEP_RUNS);
    runs.retain(|run| {
        if extra > 0 && run.routine_id == routine {
            extra -= 1;
            false
        } else {
            true
        }
    });
}
```

```rust
use std::sync::Arc;

use forge_domain::{push_run, routine_id, validate_draft, AppConfig, Routine, RoutineDraft, RoutineRun};
use forge_ports::{ConfigError, ConfigRepositoryPort};
use thiserror::Error;

use super::config_lock::ConfigLock;

#[derive(Debug, Error)]
pub enum RoutineError {
    /// The form is not valid; the text says what to fix.
    #[error("{0}")]
    Invalid(String),
    #[error("no routine called {0}")]
    NotFound(String),
    /// Run now was not possible; the text says why.
    #[error("{0}")]
    Refused(String),
    #[error("failed to read or write the Forge config: {0}")]
    Config(#[from] ConfigError),
}

/// Keeps the routines and their history in Forge's config. Every change loads, edits and saves
/// under the shared lock, and a config that cannot be read is never replaced.
pub struct RoutinesUseCase {
    config: Arc<dyn ConfigRepositoryPort>,
    write_lock: ConfigLock,
}

impl RoutinesUseCase {
    pub fn new(config: Arc<dyn ConfigRepositoryPort>) -> Self {
        Self { config, write_lock: ConfigLock::default() }
    }

    /// Shares the lock the other config writers hold (see `ConfigLock`).
    pub fn with_config_lock(mut self, lock: ConfigLock) -> Self {
        self.write_lock = lock;
        self
    }

    pub async fn snapshot(&self) -> Result<(Vec<Routine>, Vec<RoutineRun>), RoutineError> {
        let config = self.config.load().await?;
        Ok((config.routines, config.routine_runs))
    }

    async fn edit<T>(&self, change: impl FnOnce(&mut AppConfig) -> Result<T, RoutineError>) -> Result<T, RoutineError> {
        let _saving = self.write_lock.hold().await;
        let mut config = self.config.load().await?;
        let value = change(&mut config)?;
        self.config.save(&config).await?;
        Ok(value)
    }

    pub async fn create(&self, draft: RoutineDraft, now_ms: i64) -> Result<Routine, RoutineError> {
        validate_draft(&draft).map_err(RoutineError::Invalid)?;
        self.edit(|config| {
            let taken: Vec<String> = config.routines.iter().map(|routine| routine.id.clone()).collect();
            let routine = Routine {
                id: routine_id(&draft.name, &taken),
                name: draft.name.trim().to_string(),
                description: draft.description.trim().to_string(),
                instructions: draft.instructions,
                folder: draft.folder.unwrap_or_default(),
                permission_mode: draft.permission_mode,
                model: draft.model,
                schedule: draft.schedule,
                enabled: true,
                created_at: now_ms,
                baseline: now_ms,
                always_allowed: Vec::new(),
            };
            config.routines.push(routine.clone());
            Ok(routine)
        })
        .await
    }

    /// Changes everything the form holds. The id, the creation time and the allowed rules stay; the
    /// count restarts from `now_ms` only when the schedule changed.
    pub async fn update(&self, id: &str, draft: RoutineDraft, now_ms: i64) -> Result<Routine, RoutineError> {
        validate_draft(&draft).map_err(RoutineError::Invalid)?;
        self.edit(|config| {
            let routine = find(config, id)?;
            if routine.schedule != draft.schedule {
                routine.baseline = now_ms;
            }
            routine.name = draft.name.trim().to_string();
            routine.description = draft.description.trim().to_string();
            routine.instructions = draft.instructions;
            routine.folder = draft.folder.unwrap_or_default();
            routine.permission_mode = draft.permission_mode;
            routine.model = draft.model;
            routine.schedule = draft.schedule;
            Ok(routine.clone())
        })
        .await
    }

    /// Removes the routine and its history. The sessions it made stay.
    pub async fn delete(&self, id: &str) -> Result<(), RoutineError> {
        self.edit(|config| {
            find(config, id)?;
            config.routines.retain(|routine| routine.id != id);
            config.routine_runs.retain(|run| run.routine_id != id);
            Ok(())
        })
        .await
    }

    /// Switching on counts from `now_ms`, so nothing that was due while it was off runs.
    pub async fn set_enabled(&self, id: &str, enabled: bool, now_ms: i64) -> Result<Routine, RoutineError> {
        self.edit(|config| {
            let routine = find(config, id)?;
            if enabled && !routine.enabled {
                routine.baseline = now_ms;
            }
            routine.enabled = enabled;
            Ok(routine.clone())
        })
        .await
    }

    /// Adds a history line and, when `baseline` is given, moves the routine's count there. A routine
    /// deleted meanwhile only loses the baseline; the line is kept.
    pub async fn record_run(&self, run: RoutineRun, baseline: Option<i64>) -> Result<(), RoutineError> {
        self.edit(|config| {
            if let Some(baseline) = baseline {
                if let Some(routine) = config.routines.iter_mut().find(|routine| routine.id == run.routine_id) {
                    routine.baseline = baseline;
                }
            }
            push_run(&mut config.routine_runs, run);
            Ok(())
        })
        .await
    }

    /// Fills in the Claude session id of a run once it is known. A run that is gone, or already has
    /// one, is left alone.
    pub async fn set_run_session(&self, routine_id: &str, due_ms: i64, session_id: String) -> Result<(), RoutineError> {
        self.edit(|config| {
            if let Some(run) = config
                .routine_runs
                .iter_mut()
                .find(|run| run.routine_id == routine_id && run.due_ms == due_ms && run.session_id.is_none())
            {
                run.session_id = Some(session_id);
            }
            Ok(())
        })
        .await
    }

    pub async fn add_allowed(&self, id: &str, rules: Vec<String>) -> Result<Routine, RoutineError> {
        self.edit(|config| {
            let routine = find(config, id)?;
            for rule in rules {
                if !routine.always_allowed.contains(&rule) {
                    routine.always_allowed.push(rule);
                }
            }
            Ok(routine.clone())
        })
        .await
    }

    pub async fn remove_allowed(&self, id: &str, rule: &str) -> Result<Routine, RoutineError> {
        self.edit(|config| {
            let routine = find(config, id)?;
            routine.always_allowed.retain(|allowed| allowed != rule);
            Ok(routine.clone())
        })
        .await
    }
}

fn find<'a>(config: &'a mut AppConfig, id: &str) -> Result<&'a mut Routine, RoutineError> {
    config.routines.iter_mut().find(|routine| routine.id == id).ok_or_else(|| RoutineError::NotFound(id.to_string()))
}
```

```rust
use std::fmt::Display;
use std::path::{Path, PathBuf};
use std::sync::Arc;

use async_trait::async_trait;
use chrono::TimeZone;
use forge_domain::{decide, Decision, PermissionMode, Routine, RoutineRun, RunOutcome, SkipReason};

use crate::use_cases::{RoutineError, RoutinesUseCase};

/// What a host needs to start one run.
#[derive(Debug, Clone, PartialEq)]
pub struct RunRequest {
    pub routine_id: String,
    /// The due time of this run; the host reports the session id against it.
    pub due_ms: i64,
    pub folder: PathBuf,
    pub permission_mode: PermissionMode,
    pub model: Option<String>,
    pub prompt: String,
    pub title: String,
    pub allowed_tools: Vec<String>,
}

/// What the runner needs from the outside world: whether a folder exists, whether a routine's
/// session is still working in it, and a way to start a session.
#[async_trait]
pub trait RoutineHost: Send + Sync {
    fn folder_exists(&self, folder: &Path) -> bool;
    /// Whether a session this host started is still working (or waiting) in `folder`. `start` must
    /// make this true at once, so two routines due in one tick cannot both start there.
    fn busy_in(&self, folder: &Path) -> bool;
    async fn start(&self, request: RunRequest) -> Result<(), String>;
}

pub struct RoutineRunner {
    routines: Arc<RoutinesUseCase>,
    host: Arc<dyn RoutineHost>,
}

impl RoutineRunner {
    pub fn new(routines: Arc<RoutinesUseCase>, host: Arc<dyn RoutineHost>) -> Self {
        Self { routines, host }
    }

    /// One look at every routine. Called every 30 seconds, and once at start so the time Forge was
    /// closed is judged at once. A config that cannot be read ends the tick with the error.
    pub async fn tick<Tz: TimeZone>(&self, now_ms: i64, zone: &Tz) -> Result<(), RoutineError>
    where
        Tz::Offset: Display,
    {
        let (routines, _) = self.routines.snapshot().await?;
        for routine in routines {
            match decide(&routine, now_ms, zone) {
                Decision::Wait => {}
                Decision::Missed { due_ms } => {
                    let run = RoutineRun {
                        routine_id: routine.id.clone(),
                        due_ms,
                        started_ms: now_ms,
                        outcome: RunOutcome::Skipped(SkipReason::Missed),
                        session_id: None,
                    };
                    self.routines.record_run(run, Some(now_ms)).await?;
                }
                Decision::Run { due_ms } => {
                    let outcome = match self.try_start(&routine, due_ms, now_ms, zone).await {
                        Ok(()) => RunOutcome::Started,
                        Err(reason) => RunOutcome::Skipped(reason),
                    };
                    let run = RoutineRun { routine_id: routine.id.clone(), due_ms, started_ms: now_ms, outcome, session_id: None };
                    self.routines.record_run(run, Some(due_ms)).await?;
                }
            }
        }
        Ok(())
    }

    /// Starts a routine at once. It does not move the count and adds no line when it is refused:
    /// the person is told why instead.
    pub async fn run_now<Tz: TimeZone>(&self, id: &str, now_ms: i64, zone: &Tz) -> Result<(), RoutineError>
    where
        Tz::Offset: Display,
    {
        let (routines, _) = self.routines.snapshot().await?;
        let routine = routines.into_iter().find(|routine| routine.id == id).ok_or_else(|| RoutineError::NotFound(id.to_string()))?;
        self.try_start(&routine, now_ms, now_ms, zone).await.map_err(|reason| {
            RoutineError::Refused(match reason {
                SkipReason::Busy => "A session of a routine is still working in this folder.".to_string(),
                SkipReason::FolderMissing => "The folder no longer exists.".to_string(),
                SkipReason::StartFailed(error) => error,
                SkipReason::Missed => "Not run.".to_string(),
            })
        })?;
        let run = RoutineRun { routine_id: routine.id, due_ms: now_ms, started_ms: now_ms, outcome: RunOutcome::Started, session_id: None };
        self.routines.record_run(run, None).await
    }

    async fn try_start<Tz: TimeZone>(&self, routine: &Routine, due_ms: i64, now_ms: i64, zone: &Tz) -> Result<(), SkipReason>
    where
        Tz::Offset: Display,
    {
        if !self.host.folder_exists(&routine.folder) {
            return Err(SkipReason::FolderMissing);
        }
        if self.host.busy_in(&routine.folder) {
            return Err(SkipReason::Busy);
        }
        let prompt = match routine.instructions.trim() {
            "" => routine.description.trim().to_string(),
            text => text.to_string(),
        };
        let date = zone.timestamp_millis_opt(now_ms).single().map(|time| time.format("%b %-d").to_string()).unwrap_or_default();
        let request = RunRequest {
            routine_id: routine.id.clone(),
            due_ms,
            folder: routine.folder.clone(),
            permission_mode: routine.permission_mode,
            model: routine.model.clone(),
            prompt,
            title: format!("{date} – {}", routine.name),
            allowed_tools: routine.always_allowed.clone(),
        };
        self.host.start(request).await.map_err(SkipReason::StartFailed)
    }
}
```

```rust
use std::collections::HashMap;
use std::path::{Path, PathBuf};
use std::sync::{Arc, Mutex};
use std::time::{Duration, Instant};

use async_trait::async_trait;
use forge_domain::ProjectSummary;
use tokio::sync::mpsc;

use crate::live_session::{LiveSessionHandle, LiveSessionId, LiveSessionView, Phase};
use crate::registry::SessionRegistry;
use crate::routine_runner::{RoutineHost, RunRequest};
use crate::use_cases::RoutinesUseCase;

/// A session this young is never called finished: right after the send its phase may still be Idle.
const GRACE: Duration = Duration::from_secs(60);

/// Whether a routine's session has done its work and nobody needs it: idle, started a turn at some
/// point, nothing waiting for approval, not failed (a failure is for the person to look at).
pub fn is_finished(view: &LiveSessionView, age: Duration) -> bool {
    age > GRACE && view.phase == Phase::Idle && view.pending_permissions.is_empty() && view.claude_session_id.is_some()
}

/// A routine's session that is waiting for the person to answer a permission.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct WaitingRun {
    pub routine_id: String,
    pub tool_name: String,
}

struct Tracked {
    routine_id: String,
    handle: LiveSessionHandle,
    folder: PathBuf,
    started: Instant,
    notified: bool,
}

/// Starts routine sessions in the session registry and keeps track of them: which folders they
/// work in, which are finished, which wait for the person.
pub struct RegistryHost {
    registry: Arc<SessionRegistry>,
    routines: Arc<RoutinesUseCase>,
    started: mpsc::UnboundedSender<LiveSessionHandle>,
    // Never held across an `.await`.
    tracked: Mutex<HashMap<LiveSessionId, Tracked>>,
}

impl RegistryHost {
    /// The receiver gets every session this host starts, so the UI can show it.
    pub fn new(registry: Arc<SessionRegistry>, routines: Arc<RoutinesUseCase>) -> (Self, mpsc::UnboundedReceiver<LiveSessionHandle>) {
        let (started, receiver) = mpsc::unbounded_channel();
        (Self { registry, routines, started, tracked: Mutex::new(HashMap::new()) }, receiver)
    }

    /// Sessions that can be closed: finished, see `is_finished`.
    pub fn finished(&self) -> Vec<LiveSessionId> {
        self.tracked
            .lock()
            .unwrap()
            .iter()
            .filter(|(_, tracked)| is_finished(&tracked.handle.snapshot(), tracked.started.elapsed()))
            .map(|(id, _)| *id)
            .collect()
    }

    /// Stops tracking a session (it was closed).
    pub fn forget(&self, id: LiveSessionId) {
        self.tracked.lock().unwrap().remove(&id);
    }

    /// Sessions that began waiting for approval since the last call, each reported once.
    pub fn waiting(&self) -> Vec<WaitingRun> {
        let mut found = Vec::new();
        for tracked in self.tracked.lock().unwrap().values_mut() {
            let view = tracked.handle.snapshot();
            if let Some(request) = view.pending_permissions.front() {
                if !tracked.notified {
                    tracked.notified = true;
                    found.push(WaitingRun { routine_id: tracked.routine_id.clone(), tool_name: request.tool_name.clone() });
                }
            } else {
                tracked.notified = false;
            }
        }
        found
    }

    /// Rules the person answered "always allow" in a routine's session, for the routine to keep.
    fn watch(&self, request: &RunRequest, handle: &LiveSessionHandle) {
        let routines = self.routines.clone();
        let routine_id = request.routine_id.clone();
        let due_ms = request.due_ms;
        let mut updates = handle.subscribe();
        // Runs on the app's tokio runtime. Ends when the session closes (the channel ends).
        tokio::spawn(async move {
            let mut reported_session = false;
            let mut known_rules: Vec<String> = Vec::new();
            while updates.changed().await.is_ok() {
                let view = updates.borrow_and_update().clone();
                if !reported_session {
                    if let Some(id) = &view.claude_session_id {
                        reported_session = true;
                        let _ = routines.set_run_session(&routine_id, due_ms, id.0.clone()).await;
                    }
                }
                if view.allowed_rules != known_rules {
                    let new: Vec<String> = view.allowed_rules.iter().filter(|rule| !known_rules.contains(rule)).cloned().collect();
                    known_rules = view.allowed_rules.clone();
                    let _ = routines.add_allowed(&routine_id, new).await;
                }
            }
        });
    }
}

#[async_trait]
impl RoutineHost for RegistryHost {
    fn folder_exists(&self, folder: &Path) -> bool {
        folder.is_dir()
    }

    fn busy_in(&self, folder: &Path) -> bool {
        self.tracked.lock().unwrap().values().any(|tracked| {
            tracked.folder == folder && !tracked.handle.is_closed() && !is_finished(&tracked.handle.snapshot(), tracked.started.elapsed())
        })
    }

    async fn start(&self, request: RunRequest) -> Result<(), String> {
        let project = ProjectSummary { path: request.folder.clone(), exists: true, ..ProjectSummary::default() };
        let handle = self
            .registry
            .open_new(&project, request.permission_mode, request.model.clone(), Vec::new())
            .map_err(|error| error.to_string())?;
        if !request.allowed_tools.is_empty() {
            handle.allow_tools(request.allowed_tools.clone());
        }
        handle.set_title(request.title.clone());
        self.watch(&request, &handle);
        // Counted as busy from here on, before anything is sent.
        self.tracked.lock().unwrap().insert(
            handle.id(),
            Tracked { routine_id: request.routine_id.clone(), handle: handle.clone(), folder: request.folder.clone(), started: Instant::now(), notified: false },
        );
        handle.send(request.prompt);
        let _ = self.started.send(handle);
        Ok(())
    }
}
```

```rust
/// What the list shows for one routine.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct RoutineCard {
    pub id: String,
    pub name: String,
    pub description: String,
    /// "On", "Paused" or "Manual".
    pub state: String,
    pub schedule: String,
    /// A session of this routine waits for a permission answer.
    pub waiting: bool,

fn state_of(routine: &Routine) -> &'static str {
    if !routine.enabled {
        "Paused"
    } else if matches!(routine.schedule, Schedule::Manual) {
        "Manual"
    } else {
        "On"
    }
}

/// The cards for the list: filtered, searched and sorted. A manual routine is "on" for the filter
/// (it is not paused).
pub fn cards(routines: &[Routine], runs: &[RoutineRun], waiting: &[String], query: &str, filter: RoutineFilter, sort: RoutineSort) -> Vec<RoutineCard> {
    let query = query.trim().to_lowercase();
    let last_run = |id: &str| runs.iter().filter(|run| run.routine_id == id).map(|run| run.due_ms).max();
    let mut chosen: Vec<&Routine> = routines
        .iter()
        .filter(|routine| match filter {
            RoutineFilter::All => true,
            RoutineFilter::On => routine.enabled,
            RoutineFilter::Paused => !routine.enabled,
        })
        .filter(|routine| query.is_empty() || routine.name.to_lowercase().contains(&query) || routine.description.to_lowercase().contains(&query))
        .collect();
    match sort {
        RoutineSort::Name => chosen.sort_by_key(|routine| routine.name.to_lowercase()),
        RoutineSort::Created => chosen.sort_by_key(|routine| std::cmp::Reverse(routine.created_at)),
        RoutineSort::LastRun => chosen.sort_by_key(|routine| std::cmp::Reverse(last_run(&routine.id))),
    }
    chosen
        .into_iter()
        .map(|routine| RoutineCard {
            id: routine.id.clone(),
            name: routine.name.clone(),
            description: routine.description.clone(),
            state: state_of(routine).to_string(),
            schedule: routine.schedule.label(),
            waiting: waiting.contains(&routine.id),
        })
        .collect()
}

    pub fn new() -> Self {
        Self {

            description: String::new(),
            instructions: String::new(),
            folder: None,
            mode: PermissionMode::Default,
            model: None,
            kind: ScheduleKind::Daily,

            minute: 0,
            day: 1,
            cron: "0 9 * * *".to_string(),
        }
    }

    pub fn from_routine(routine: &Routine) -> Self {
        let mut form = Self {
            name: routine.name.clone(),
            description: routine.description.clone(),
            instructions: routine.instructions.clone(),
            folder: Some(routine.folder.clone()),
            mode: routine.permission_mode,
            model: routine.model.clone(),
            ..Self::new()
        };
        match &routine.schedule {
            Schedule::Manual => form.kind = ScheduleKind::Manual,
            Schedule::Hourly => form.kind = ScheduleKind::Hourly,
            Schedule::Daily { hour, minute } => (form.kind, form.hour, form.minute) = (ScheduleKind::Daily, *hour, *minute),

            Schedule::Weekly { day, hour, minute } => (form.kind, form.day, form.hour, form.minute) = (ScheduleKind::Weekly, *day, *hour, *minute),
            Schedule::Cron { expression } => (form.kind, form.cron) = (ScheduleKind::Custom, expression.clone()),
        }
        form
    }

    fn schedule(&self) -> Schedule {
        match self.kind {
            ScheduleKind::Manual => Schedule::Manual,
            ScheduleKind::Hourly => Schedule::Hourly,
            ScheduleKind::Daily => Schedule::Daily { hour: self.hour, minute: self.minute },
            ScheduleKind::Weekdays => Schedule::Weekdays { hour: self.hour, minute: self.minute },
            ScheduleKind::Weekly => Schedule::Weekly { day: self.day, hour: self.hour, minute: self.minute },
            ScheduleKind::Custom => Schedule::Cron { expression: self.cron.trim().to_string() },
        }
    }

        RoutineDraft {
            name: self.name.clone(),
            description: self.description.clone(),
            instructions: self.instructions.clone(),
            folder: self.folder.clone(),

            model: self.model.clone(),

    }

    pub due_ms: i64,
    pub text: String,
    /// The session to open on a click; `None` for a skip.

pub fn skip_text(reason: &SkipReason) -> String {
    match reason {
        SkipReason::Missed => "Skipped: Forge was closed or the computer was asleep".to_string(),
        SkipReason::Busy => "Skipped: a session of this routine's folder was still working".to_string(),
        SkipReason::FolderMissing => "Skipped: the folder no longer exists".to_string(),
        SkipReason::StartFailed(error) => format!("Skipped: could not start ({error})"),
    }
}

/// The history of one routine, newest first. `state_of` names what a started run is now ("Running",
/// "Waiting for approval", "Done"), read from its session by the caller.
pub fn history_rows(runs: &[RoutineRun], routine_id: &str, state_of: &dyn Fn(&str) -> &'static str) -> Vec<HistoryRow> {
    let mut rows: Vec<&RoutineRun> = runs.iter().filter(|run| run.routine_id == routine_id).collect();
    rows.sort_by_key(|run| std::cmp::Reverse(run.due_ms));
    rows.into_iter()
        .map(|run| match &run.outcome {
            RunOutcome::Started => HistoryRow {
                due_ms: run.due_ms,
                text: state_of(run.session_id.as_deref().unwrap_or("")).to_string(),
                session_id: run.session_id.clone(),
            },
            RunOutcome::Skipped(reason) => HistoryRow { due_ms: run.due_ms, text: skip_text(reason), session_id: None },
        })
        .collect()
}

const MONTHS: [&str; 12] = ["Jan", "Feb", "Mar", "Apr", "May", "Jun", "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"];

/// "Oct 9, 10:19 AM" in `offset`.
pub fn when_label(ms: i64, offset: time::UtcOffset) -> String {
    let Ok(utc) = time::OffsetDateTime::from_unix_timestamp(ms.div_euclid(1000)) else {
        return String::new();
    };
    let local = utc.to_offset(offset);
    let hour = local.hour();
    let (twelve, suffix) = match hour {
        0 => (12, "AM"),
        1..=11 => (hour, "AM"),
        12 => (12, "PM"),
        _ => (hour - 12, "PM"),
    };
    format!("{} {}, {twelve}:{:02} {suffix}", MONTHS[usize::from(u8::from(local.month())) - 1], local.day(), local.minute())
}
```

```rust
    pub fn reload(&self) {
        let this = *self;
        let usecase = self.services.peek().routines.routines.clone();
        dioxus::core::spawn_forever(async move {
            match usecase.snapshot().await {
                Ok((routines, runs)) => {
                    let (mut r, mut u) = (this.routines, this.runs);
                    r.set(routines);
                    u.set(runs);
                }
                Err(error) => this.fail(error),
            }
        });
    }

    fn fail(&self, error: RoutineError) {
        let mut e = self.error;
        e.set(Some(error.to_string()));
    }

    /// Runs `job` against the use case, then re-reads. One job at a time (`busy`).
    fn run_job<F, Fut>(&self, job: F)
    where
        F: FnOnce(std::sync::Arc<RoutinesUseCase>, std::sync::Arc<RoutineRunner>) -> Fut + 'static,
        Fut: std::future::Future<Output = Result<Option<RoutineScreen>, RoutineError>> + 'static,
    {
        if self.busy() {
            return;
        }
        let this = *self;
        let services = self.services.peek().routines.clone();
        let mut busy = self.busy;
        busy.set(true);
        dioxus::core::spawn_forever(async move {
            let result = job(services.routines.clone(), services.runner.clone()).await;
            let mut busy = this.busy;
            busy.set(false);
            match result {
                Ok(next) => {
                    this.clear_error();
                    if let Some(screen) = next {
                        let mut s = this.screen;
                        s.set(screen);
                    }
                    this.reload();
                }
                Err(error) => this.fail(error),
            }
        });
    }

    /// Saves the form: creates the routine or updates the one being edited.
    pub fn submit_form(&self) {
        let form = self.form();
        let editing = match self.screen() {
            RoutineScreen::Form(id) => id,
            _ => return,
        };
        self.run_job(move |routines, _| async move {
            let saved = match editing {
                Some(id) => routines.update(&id, form.to_draft(), now_ms()).await?,
                None => routines.create(form.to_draft(), now_ms()).await?,
            };
            Ok(Some(RoutineScreen::Detail(saved.id)))
        });
    }

    pub fn set_enabled(&self, id: String, enabled: bool) {
        self.run_job(move |routines, _| async move {
            routines.set_enabled(&id, enabled, now_ms()).await?;
            Ok(None)
        });
    }

    pub fn delete(&self, id: String) {
        self.close_dialog();
        self.run_job(move |routines, _| async move {
            routines.delete(&id).await?;
            Ok(Some(RoutineScreen::List))
        });
    }

    pub fn remove_allowed(&self, id: String, rule: String) {
        self.run_job(move |routines, _| async move {
            routines.remove_allowed(&id, &rule).await?;
            Ok(None)
        });
    }

    /// Starts the routine at once and shows the session it made.
    pub fn run_now(&self, id: String, workspace: Workspace) {
        let this = *self;
        self.run_job(move |_, runner| async move {
            runner.run_now(&id, now_ms(), &chrono::Local).await?;
            Ok(None)
        });
        // The session is adopted by the timer's drain; do it now too so it is on screen at once.
        dioxus::core::spawn_forever(async move {
            tokio::time::sleep(Duration::from_millis(400)).await;
            this.adopt_started(workspace);
        });
    }

    /// Picks the folder for the form with the system picker.
    pub fn choose_folder(&self) {
        let picker = self.services.peek().folder_picker.clone();
        let this = *self;
        dioxus::core::spawn_forever(async move {
            if let Some(folder) = picker.pick_folder().await {
                this.edit_form(|form| form.folder = Some(folder));
            }
        });
    }

    /// Shows every session the host started since the last look, and closes the finished ones that
    /// are not on screen.
    fn adopt_started(&self, workspace: Workspace) {
        let services = self.services.peek().routines.clone();
        let handles: Vec<_> = {
            let mut receiver = services.starts.lock().unwrap();
            std::iter::from_fn(|| receiver.try_recv().ok()).collect()
        };
        for handle in handles {
            workspace.adopt(handle);
        }
        for id in services.host.finished() {
            if workspace.active() != Active::Live(id) {
                workspace.close(id);
                services.host.forget(id);
            }
        }
    }

    fn start_timer(&self, workspace: Workspace) {
        let this = *self;
        dioxus::core::spawn_forever(async move {
            loop {
                let services = this.services.peek().routines.clone();
                if let Err(error) = services.runner.tick(now_ms(), &chrono::Local).await {
                    this.fail(error);
                }
                this.adopt_started(workspace);
                let waiting: Vec<String> = services.host.waiting().into_iter().map(|run| run.routine_id).collect();
                if !waiting.is_empty() {
                    let mut w = this.waiting;
                    w.set(waiting);
                }
                this.reload();
                tokio::time::sleep(TICK).await;
            }
        });
    }
}
```

```rust
use forge_ports::NotifyPort;

/// What `osascript` is given: a fixed script that reads its title and body from the arguments.
pub(crate) fn osascript_arguments(title: &str, body: &str) -> Vec<String> {
    vec![
        "-e".to_string(),
        "on run argv".to_string(),
        "-e".to_string(),
        "display notification (item 2 of argv) with title (item 1 of argv)".to_string(),
        "-e".to_string(),
        "end run".to_string(),
        title.to_string(),
        body.to_string(),
    ]
}

/// macOS: a notification through `osascript`.
pub struct OsascriptNotify;

impl OsascriptNotify {
    pub fn new() -> Self {
        Self
    }
}

impl Default for OsascriptNotify {
    fn default() -> Self {
        Self::new()
    }
}

impl NotifyPort for OsascriptNotify {
    fn notify(&self, title: &str, body: &str) -> Result<(), String> {
        let output = std::process::Command::new("osascript").args(osascript_arguments(title, body)).output().map_err(|error| error.to_string())?;
        if output.status.success() {
            Ok(())
        } else {
            Err(String::from_utf8_lossy(&output.stderr).trim().to_string())
        }
    }
}

/// Where there is no adapter (Windows in this plan): says so, so the caller can ignore it.
pub struct NoNotify;

impl NotifyPort for NoNotify {
    fn notify(&self, _title: &str, _body: &str) -> Result<(), String> {
        Err("notifications are not available here".to_string())
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn the_text_is_passed_as_arguments_and_never_as_script() {
        let arguments = osascript_arguments("Routine \"x\"; do shell script \"rm -rf ~\"", "it's here");
        // The three script lines never contain the text; the last two arguments are the text itself.
        assert!(arguments[..6].iter().all(|part| !part.contains("rm -rf")));
        assert_eq!(arguments[6], "Routine \"x\"; do shell script \"rm -rf ~\"");
        assert_eq!(arguments[7], "it's here");
    }

    #[test]
    fn nothing_is_available_without_an_adapter() {
        assert!(NoNotify.notify("a", "b").is_err());
    }
}
```
